# Skill disponibili per Erga

Tutte le skill utilizzabili dagli assistenti sono state riunite nella cartella unica:

[`/.agents/skills/`](../../.agents/skills/README.md)

Il catalogo descrive ogni skill, quando usarla e quali sono specifiche di piattaforme non ancora presenti nel progetto.

## File di controllo

- [`AGENTS.md`](../../AGENTS.md): regole operative e priorità specifiche di Erga.
- [`PRODUCT.md`](../../PRODUCT.md): utenti, scopo, posizionamento e vincoli confermati.
- [`skills-lock.json`](../../skills-lock.json): sorgenti e hash delle skill installate tramite CLI.
- [`DESIGN.md`](../../DESIGN.md): sistema visivo confermato (colori, caratteri, layout, elevazione, forme, componenti, regole).
- [`.impeccable/design.json`](../../.impeccable/design.json): gettoni estesi e componenti renderizzabili per il pannello Impeccable.
- [`.impeccable/config.json`](../../.impeccable/config.json): configurazione del workflow Impeccable.

Le skill sono documentazione per gli assistenti e non vengono incluse nella build dell'applicazione.
